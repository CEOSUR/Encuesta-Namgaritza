# CEO SUR – Encuesta Digital Nangaritza 2027

Repositorio independiente de la aplicación de encuestas de campo de CEO SUR. Despliegue previsto en Railway.

## Archivos de aplicación

La aplicación requiere `index.html`, `server.js` y `package.json` del paquete **CEO_SUR_Nangaritza_WEB_LISTA_PUBLICAR.zip** preparado para esta publicación. Mantener juntos los archivos en la raíz del repositorio.

## Privacidad y datos

La versión offline conserva respuestas en el navegador de cada dispositivo y requiere exportar respaldos periódicos. No existe sincronización automática entre teléfonos. No publicar respaldos de encuestas ni información personal en este repositorio.
